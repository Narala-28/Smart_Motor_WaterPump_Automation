# Contributing

Contributions are welcome for documentation, testing, bug fixes and feature improvements.

## Before submitting changes

1. Explain the reason for the change.
2. Avoid committing Wi-Fi passwords, Blynk tokens or other secrets.
3. Keep motor-control changes clearly documented.
4. Test on a safe isolated bench setup before field use.
5. Do not bypass electrical protection in a live installation.
6. Keep the firmware compatible with the documented ESP32 and Arduino environment.

## Pull Requests

Please include:

- What changed
- Why it changed
- How it was tested
- Any hardware or Blynk dashboard changes
